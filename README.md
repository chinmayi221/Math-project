# Three-Species Ecosystem Modeling Using Linear Algebra

## Introduction
This project models and predicts the population dynamics of three marine species: Herring, Whiting, and Cod at Hinkley Point. Using historical population data, a transition matrix is estimated through least-squares fitting. Linear algebra techniques, including eigenvalue analysis, matrix diagonalization, and convergence analysis, are used to study ecosystem stability and forecast future population trends.

## Requirements
Download only these two files from the repository:
- main.py
- hinkley.csv

## Installation
Install the required Python libraries:

pip install numpy pandas matplotlib


## Run
Keep main.py and hinkley.csv in the same folder and execute:


python main.py


The program generates the required data files, numerical results, and visualizations automatically.
